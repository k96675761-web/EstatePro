ESTATEPRO — LUXURY REAL ESTATE DEMO

Files:
- index.html: website structure and content
- style.css: responsive black-and-gold styling
- script.js: property filtering, details modal, favorites, mobile navigation, demo contact form

Run locally:
Open index.html in your browser. Internet is needed for the external images and Google Fonts.

GitHub Pages:
1. Upload index.html, style.css and script.js to the root of your GitHub repository.
2. Open repository Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait for deployment and open the URL GitHub Pages displays.

This is a front-end demo. Property listings and contact form are sample content. The contact form does not send messages to a server.
